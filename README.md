# 校园内网登录器

**中文名**：校园内网登录器
**英文名**：Campus Network Login Client，简称 **CNLC**

> 检测到断网后，自动执行 portal 认证登录，保持网络持续在线。
> 针对高校校园网（华为 AC Portal 1.1.1.3 认证）环境定制。
> **纯 C# / WinForms 编写的原生 exe**（Windows 自带 csc.exe 编译，无第三方打包器，极少被杀毒软件误报）。

## 软件简介

校园内网登录器（CNLC）是一款面向校园网 Portal 认证环境的 Windows 托盘工具，解决学校教室希沃大屏"每次联网都要手动打开网页输账号密码、打开雨课堂网页版需要手工输入网址"的痛点。程序启动后常驻系统托盘：一键完成 Portal 认证；支持断网后每 30 秒自动检测并重新认证；支持记住密码、开机自登录——开机即联网，全程无感；点击"雨课堂网页版"按钮，一键直达学校雨课堂门户，无需手工输入网址。整个程序为单个 exe 文件（约 39 KB），绿色免安装，在本地配置好账号密码后，拷贝程序所在文件夹到 U 盘即可在任意实验室/办公室电脑使用。

## 功能说明

| 功能 | 说明 |
|---|---|
| **登录** | 立即向 portal 发起认证（跳过检测等待），1~2 秒内完成 |
| **注销** | 向 portal 发送注销请求，网络随之断开；随后可重新登录 |
| **记住密码** | 账号密码以 Base64 编码保存在 exe 旁的 **`CNLC.dat`**（隐藏+系统属性，不易误删误看）。**跨电脑通用**：把 exe 连同此文件拷到别的电脑，照样自动登录（非加密，仅防直接看到） |
| **断网自动重连** | 每 30 秒检测一次网络，断网后自动 RC4 认证重连；托盘右键菜单同步此开关 |
| **开机自登录** | 一项搞定两个动作：勾选后写入注册表 Run 项（开机自启动，无需管理员权限）+ 静默登录标记，开机后无窗口直接进托盘守护（需先勾选"记住密码"并登录一次） |
| **雨课堂网页版** | 按钮式入口：点击即用默认浏览器打开学校雨课堂门户，同时把主界面最小化到托盘 |
| **显示主界面** | 托盘右键 → 显示主界面，重新打开登录窗口，修改账号后重新登录即可切换 |
| **登录结果提示** | 登录后显示"登录成功"或失败原因的彩色浮条，3 秒自动消失，不打扰操作 |
| **检查更新** | 托盘右键 → 关于 → 检查更新：联网比对 Gitee 最新 Release 的版本号，发现新版可一键打开下载页。**只有作者手动发布的 Release 才对用户可见**，main 分支的日常提交不影响用户端 |

### 托盘操作

- **左键点击图标**：弹出运行状态窗口（当前账号 / 实时网络状态 / 检测间隔 / 最近检测与成功登录时间，本次运行期间）；屏幕上任意位置点击或按任意键即自动关闭
- **右键图标**：显示主界面 → 断网自动重连（开关）→ 关于 → 注销 → 退出
- 所有气泡通知已全局关闭，除登录结果浮条外完全静默

## 工作原理

- **检测**：每 30 秒访问 `https://www.baidu.com`，不通则判定断网
- **认证**：密码按校园网前端要求做 RC4 加密（密钥=毫秒时间戳），POST 到 `http://1.1.1.3/ac_portal/login.php`（`opr=pwdLogin`）
- **注销**：同接口 `opr=logout`，服务器按 IP 注销会话（注销后有短暂冷却期，程序会自动重试）
- **单实例**：Mutex 保证同时只有一个 CNLC 运行
- **零残留**：不生成任何日志或状态文件，程序目录只有 exe 与凭据文件

## 从源码构建

无需安装任何第三方工具，Windows 自带的 .NET Framework 编译器即可：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Exe.ps1
```

- 脚本自动定位 `csc.exe`，编译 `CNLC.cs` → `CNLC\CNLC.exe`（嵌入图标）
- 构建前会自动停止正在运行的 CNLC 进程

## 发布新版本（作者用）

采用 **Release 发布制**：main 分支的日常提交对用户不可见，只有手动创建的 Release 才会被"检查更新"识别。

1. 修改代码，把 `CNLC.cs` 中的 `AppVersion` 升级（如 1.3.4 → 1.3.5），提交推送
2. 运行 `Build-Exe.ps1` 编译出 `CNLC\CNLC.exe`
3. 到 Gitee 仓库页 → "创建发布"→ 填写 tag（如 `v1.3.5`）→ 上传 `CNLC.exe` → 发布

完成后，用户端"检查更新"即可发现新版。删除某个 Release 即可撤回该版本的更新提示。

## 常见问题

**Q: 换一台电脑能用吗？**
A: 能。拷贝 `CNLC.exe`（可选带 `CNLC.dat` 保留记住的密码）到新电脑即可，不绑定本机。

**Q: 账号密码安全吗？**
A: 密码提交前按校园网要求 RC4 加密，只发给认证服务器（1.1.1.3）；本地仅保存 Base64 编码（非加密）。程序不含账号密码出厂值。

**Q: 注销后再点登录为什么要等一会？**
A: portal 注销后服务器端有短暂冷却期。点"登录"会立即发起认证并自动重试，通常 1~2 秒恢复。

**Q: 被杀毒软件误报怎么办？**
A: 本程序为原生 .NET exe，误报概率远低于脚本打包器（ps2exe 等）。若仍被拦截，添加信任即可。
