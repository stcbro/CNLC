# 校园内网登录器

**中文名**：校园内网登录器  
**英文名**：Campus Network Login Client，简称 **CNLC**

## 软件简介

校园内网登录器（CNLC）是一款面向校园网 Portal 认证环境的 Windows 托盘工具，解决学校教室希沃大屏“每次联网都要手动打开网页输账号密码、打开雨课堂网页版需要手工输入网址”的痛点。程序启动后常驻系统托盘：一键完成 Portal 认证；支持断网后每 30 秒自动检测并重新认证；支持记住密码、开机自登录——开机即联网，全程无感；点击“雨课堂网页版”按钮，一键直达学校雨课堂门户，无需手工输入网址。整个程序为单个 exe 文件，绿色免安装，在本地配置好账号密码后，拷贝**程序所在文件夹**到 U 盘即可在任意实验室/办公室电脑使用。

## 运行环境

| 项目 | 要求 |
|---|---|
| **操作系统** | Windows 7 SP1 及以上（Windows 8 / 10 / 11 均可直接运行） |
| **.NET Framework** | 4.0 及以上。Windows 8/10/11 系统自带，一般**无需额外安装**；Windows 7 若提示缺组件，先安装 .NET Framework 4.x 运行时 |
| **用户权限** | 普通用户权限即可，全程**无需管理员**（开机自登录仅写当前用户注册表 Run 项） |
| **网络** | 接入校园网，Portal 认证网关（`1.1.1.3`）可达 |
| **显示** | 任意分辨率与 DPI 缩放（100% / 125% / 150% 均自适应，含触摸一体机大屏） |
| **磁盘占用** | 单文件约 65 KB；运行时在 exe 旁生成凭据文件 `CNLC.dat`（约 100 字节） |

## 功能说明

| 功能         | 说明                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| **登录**     | 立即向 portal 发起认证（跳过检测等待），1~2 秒内完成                                                                         |
| **注销**     | 向 portal 发送注销请求，网络随之断开；随后可重新登录                                                                           |
| **记住密码**   | 账号密码以 Base64 编码保存在 exe 旁的 **`CNLC.dat`**（普通数据文件）。**跨电脑通用**：把 exe 连同此文件拷到别的电脑，照样自动登录（非加密，仅防直接看到）  |
| **断网自动重连** | 每 30 秒检测一次网络，断网后自动 RC4 认证重连；托盘右键菜单同步此开关                                                                  |
| **开机自登录**  | 一项搞定两个动作：勾选后写入注册表 Run 项（开机自启动，无需管理员权限）+ 静默登录标记，开机后无窗口直接进托盘守护（需先勾选“记住密码”并登录一次）                            |
| **定时重启电脑** | 托盘右键 → 定时重启电脑：默认每日 **00:00**（时间可自选，**按电脑生效**），通过 Windows 计划任务重启电脑，缓解长时间运行卡顿。仅在无人操作满 30 分钟时执行（有人在用就跳过当天）；重启前留 60 秒倒计时，可取消；无需管理员权限 |
| **雨课堂网页版** | 按钮式入口：点击即用默认浏览器打开学校雨课堂门户，同时把主界面最小化到托盘                                                                    |
| **显示主界面**  | 托盘右键 → 显示主界面，重新打开登录窗口，修改账号后重新登录即可切换                                                                      |
| **登录结果提示** | 登录后显示“登录成功”或失败原因的彩色浮条，3 秒自动消失，不打扰操作                                                                       |
| **检查更新**   | 托盘右键→关于→检查更新：联网比对 `update.json` 指针版本，发现新版可**一键自动更新**——自动下载并校验（PE 头 + SHA256）、原地换身替换、继承账号密码静默登录，数秒完成；任一步失败自动回滚并提示。 |
| **托盘操作**   | 左键点击图标弹出运行状态窗口（当前账号 / 实时网络状态 / 检测间隔 / 最近检测与成功登录时间，本次运行期间），窗口内任意点击或按任意键、点击窗口外失焦即关闭；右键菜单：显示主界面 → 断网自动重连（开关）→ 定时重启电脑 → 关于 → 注销 → 退出                                                       |

## 工作原理

- **检测**：每 30 秒访问 `https://www.baidu.com`，不通则判定断网
- **认证**：密码按校园网前端要求做 RC4 加密（密钥=毫秒时间戳），POST 到 `http://1.1.1.3/ac_portal/login.php`（`opr=pwdLogin`）
- **注销**：同接口 `opr=logout`，服务器按 IP 注销会话（注销后有短暂冷却期，程序会自动重试）
- **单实例**：Mutex 保证同时只有一个 CNLC 运行
- **零残留**：不生成任何日志或状态文件，程序目录只有 exe 与凭据文件（定时重启的时间回显存当前用户注册表）

## 常见问题

**Q: 换一台电脑能用吗？**  
A: 能。拷贝 `CNLC.exe`（可选带 `CNLC.dat` 保留记住的密码）到新电脑即可，不绑定本机。

**Q: 账号密码安全吗？**  
A: 密码提交前按校园网要求 RC4 加密，只发给认证服务器（1.1.1.3）；本地仅保存 Base64 编码（非加密）。程序不含账号密码出厂值。

**Q: 注销后再点登录为什么要等一会？**  
A: portal 注销后服务器端有短暂冷却期。点“登录”会立即发起认证并自动重试，通常 1~2 秒恢复。

**Q: 被 360 等杀毒软件误报/隔离了怎么办？**  
A: 程序无数字签名，且包含“写自启动注册表 + RC4 加密凭据”等行为，个别杀软（尤其 360）的启发式引擎可能误报。按需选择：

1. **恢复并信任**（本机立即解决）：360 安全卫士 → 木马查杀 → **恢复区** → 勾选 `CNLC.exe` → 恢复并加入信任；或在 **信任区** 直接添加 `CNLC.exe`（或整个程序文件夹）
2. **提交误报申诉**（一劳永逸，全网生效）：到 360 开放平台 [open.soft.360.cn](https://open.soft.360.cn) 提交误报申诉，审核通过后云端白名单对所有用户生效，一般 1~3 个工作日
3. **自行审阅**：全部源码就是本仓库的单文件 `CNLC.cs`（约 2000 行），逻辑完全透明，也可用 Windows 自带编译器自行编译
